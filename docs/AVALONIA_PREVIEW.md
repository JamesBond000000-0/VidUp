# Avalonia GUI Preview（最初の実装）

作成日: 2026-10-24。設計書のP1に向けた初期Shellであり、P1全体の完了ではありません。

環境構築は [開発環境のセットアップ](DEVELOPMENT_ENVIRONMENT.md) を参照してください。

## 起動

.NET 10 SDK、デスクトップ環境、NuGetへの接続が必要です。
Windowsでの確認を優先します。LinuxではAvaloniaのネイティブ依存とGUI環境が別途必要です。
ブラウザで動くWeb版ではありません。

```sh
dotnet restore VidUp.Desktop/VidUp.Desktop.csproj
dotnet run --project VidUp.Desktop/VidUp.Desktop.csproj
```

テスト（GUIを起動しないViewModelテスト）:

```sh
dotnet test VidUp.Desktop.Tests/VidUp.Desktop.Tests.csproj -c Release
```

## 今回実装したもの

- Avalonia 11.3.0 / .NET 10、標準Fluentテーマ。パッケージは同一バージョンに固定。
- 常設ナビゲーション、動画キュー、読取専用の詳細ペイン。
- 横幅が狭いときのキュー/詳細の縦配置。
- システム追従/ライト/ダークの切替（保存しない）。
- 明示的なサンプル3件、動画名/アカウント検索、選択連動。
- ネイティブファイル選択、ファイルのドラッグ＆ドロップ。
- 拡張子と存在確認、パスの正規化、重複除外、追加/スキップ件数表示。
- 仮想化ListBox。クリアはメモリ内だけで行い、元ファイルを消さない。
- Windows/Linuxのビルド・ViewModelテストと、Windows向けプレビュー成果物を作るCI定義。

## 安全性と制限

- Business / Youtube / Json / Utils / WPFへのプロジェクト参照はありません。
- 既存プロファイルの読込・保存、認証、通信、実アップロード、電源操作は実装していません。
- 動画ファイルの内容を読み込むこともありません。拡張子チェックはYouTubeが受け付ける形式や動画の健全性を保証しません。
- 終了すると追加内容・テーマ・検索条件はすべて消えます。
- 開始ボタンは無効です。他のナビゲーション先は未実装と明記したプレースホルダーです。
- 現時点では日本語表示のみ。文言のリソース化、英語、編集、一括操作、列設定、スケジュールは後続対応です。
- 大量ファイルの存在確認は現在UIスレッドで行います。非同期検証・大量追加の性能測定は次段階の課題です。
- 読取専用プロファイルインポートは今回含めていません。専用コピー限定の安全策と一緒に後続追加します。
- Avalonia 11.3.0で必要なAPIのソースを一部確認しましたが、.NET 10との実行互換性を含めCI/実機での検証が必要です。

## 確認手順と結果の記録

第三者へ確認を依頼する際は、[検証・引き継ぎチェックリスト](AVALONIA_VERIFICATION_CHECKLIST.md) を使用してください。
環境準備、各操作の意図・手順・期待結果・証跡、結果記録テンプレート、完了条件をまとめています。
必須項目のFAIL/BLOCKEDが残る間は確認完了とせず、未実装項目は後続ゲートへ引き継ぎます。
